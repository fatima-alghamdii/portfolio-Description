# Reserve Your Locker

A web-based locker reservation system developed as a graduation project in Computer Information Systems.

## Project Overview

The system allows university students to register, view available lockers, select a locker and reservation period, and choose a payment method.

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap
- PHP
- MySQL

## Main Features

- Student registration and login
- Locker availability and selection
- Locker reservation
- Online and cash payment options
- Reservation confirmation
- Admin reservation management
